## Conversations

- **Channels** are public (anyone in the workspace can join) or private (invite only). Each has a topic, members, a bookmarks bar and tabs for Canvas, Board, Whiteboard and Files.
- **Direct messages** work one-to-one or with a small group.
- **Threads** keep side conversations next to the message they're about. Follow threads from the **Threads** view.

## Writing messages

- Formatting: `*bold*`, `_italic_`, `~strike~`, `` `code` ``, code blocks with syntax highlighting, quotes and links.
- Mention people with `@name`, a whole group with `@design`, or everyone with `@here`, `@channel` or `@everyone`.
- Attach files, record a **voice message** or a **video clip**, or record your screen.
- Press <kbd>↑</kbd> in an empty composer to edit your last message. Edits keep a history.
- Drafts are saved per conversation.

## Doing more with a message

- **React** with any emoji, **pin** important messages, and **save** them for later.
- **Forward** a message to other channels or DMs, or **copy its link** to share it anywhere in the workspace.
- **Schedule** a message for later (for example "tomorrow at 9:00"). Find, edit or send scheduled messages in **Drafts & sent**.
- Create a **poll** with single or multiple choice, anonymous if you like.
- Links show a preview card, fetched safely by the server.

## Slash commands

Type `/` in the composer to see them all, including `/remind`, `/poll`, `/dnd`, `/mute`, `/status`, `/away`, `/topic`, `/invite`, `/leave`, `/shrug` and `/ai`.

![The slash command menu](/screenshots/slash-commands.webp)

## Search

Press <kbd>⌘K</kbd> (or <kbd>Ctrl K</kbd>) and search. Narrow results with filters:

| Filter | Example |
|---|---|
| `from:` | `from:@maya` |
| `in:` | `in:#launch` |
| `has:` | `has:link`, `has:file`, `has:image`, `has:pin`, `has:reaction` |
| `before:` / `after:` / `on:` | `after:2026-11-01` |
| `is:thread` | messages in threads |
| `"exact phrase"` | `"release notes"` |

![Search with filters](/screenshots/search.webp)

## Long histories

Scroll up to load older messages. Following a link to an old message loads the conversation around it; use **Jump to latest** to come back to the present.
